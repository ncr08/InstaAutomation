## Summary

Asking for a written plan before any code changes catches wrong assumptions while they are still cheap to fix.

## The technique

Start in plan mode, review the plan, correct it, and only then let the agent edit.

## Step-by-step instructions

1. Press Shift+Tab until plan mode is on
2. Describe the refactor and ask for a step-by-step plan
3. Correct anything wrong in the plan
4. Approve it and let Claude make the changes

## Prerequisites

- Claude Code installed

## When this is useful

Before any change that touches more than a few files.

## Caveats

- A plan is only as good as the context you give it
